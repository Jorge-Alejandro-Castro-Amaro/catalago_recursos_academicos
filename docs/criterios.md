1. **Tipo de recurso**  
   - Identifica la naturaleza del material: libro, artículo, sitio web, video, herramienta de software, etc.  

2. **Tema o área de conocimiento**  
   - Clasifica el recurso según la disciplina o campo académico al que pertenece (ejemplo: matemáticas, informática, historia, biología).  

3. **Nivel académico**  
   - Determina la profundidad o complejidad del recurso: básico, intermedio, avanzado, especializado.  

4. **Autor o fuente**  
   - Registra quién creó o publicó el recurso, así como la institución o plataforma que lo respalda, para garantizar confiabilidad y referencia.
