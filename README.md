Nombre: Technology-Facturation.

Descripcion: La aplicación representa la estructura inicial de un sistema que posteriormente podría registrar y consultar libros, sitios web, videos, artículos y herramientas de software.

Objetivo: Servir como una estructura base para un sistema que, en etapas posteriores, pueda registrar y consultar distintos tipos de recursos de información como libros, sitios web, videos, artículos y herramientas de software, ofreciendo un punto de partida para su organización y gestión dentro de una plataforma unificada.

Estructura general: Esqueleto modular que define las bases  (libros, sitios web, videos, artículos y herramientas de software).para manejar distintos tipos de recursos (libros, sitios web, videos, artículos y herramientas de software).

Tecnoligias utilizadas: Python, Git.

Intrucciones:
1.- crear la carpeta en la ubicacion deseada.
2.- crear el entorno virtual con el comando py -m venv .venv 
3.- activar el entorno virtual con .venv/scripts/activate
